# PMUX优化系统

本项目基于 Yosys v0.69 开发 PMUX 优化 pass，通过选择条件分析、
嵌套选择结构重建和跨分支算术共享，降低综合后的逻辑资源数量。

当前发布版本：r11。

## 源码与文档

- pmux_opt.cc：核心优化算法，供在线阅读。
- candidate-source.tar：本次冻结版本的完整候选源码。
- 技术报告.pdf：算法原理、系统组成、验证方法和测试结果。
- 使用说明.md：完整交付包的运行与验证方法。
- BUILD.md：完整交付包中的源码重编译说明。
- summary.tsv：九个测试用例的正式结果汇总。
- COPYING、licenses：上游及第三方组件许可证。

运行说明和构建说明中的目录结构，均指 Release 完整包解压后的目录。

## 下载与运行

请进入本仓库的 Releases 页面，下载 PMUX优化系统-r11.rar。

完整包包含原版和优化版 Yosys、依赖库、源码、九个测试用例、
验证脚本和原始证据。解压后按照包内 README.md 操作。

外部验证环境需要 Windows、Python 3.12 或更新版本、
OSS CAD Suite 和 MSYS2 Bash，具体要求见使用说明。

## 本地验证结果

- 原版和优化版各九项完整 EQY 证明，共 18/18 项通过。
- 九例逻辑资源缩减率的算术平均为 21.038473%。
- 每个用例的逻辑资源均减少。
- 按固定复核协议，最大墙钟时间增幅为 3.118842%。
- 最大主进程峰值内存增幅为 2.816901%。
- 九例时间和内存指标均在 5% 增幅以内。

完整 RAR 已通过完整性检查，并在新目录解压后实际运行九例，
资源统计与正式报告一致。

以上为本地公开 Yosys v0.69 同源配对测试结果。
官方构建及环境差异、初始化模型和复核规则见技术报告，
最终成绩以官方评测为准。
